# Garment Store

Next.js 16 (App Router, Cache Components) + Tailwind v4 + shadcn/ui (Base UI) + zustand.

```bash
npm install
npm run dev      # http://localhost:3000
npm run lint     # biome
npx tsc --noEmit
```

`PageProps` / `LayoutProps` are generated by Next. If `tsc` reports them as missing, run
`npx next typegen` first (`next dev` and `next build` do it too).

## Routes

| Route | What it is |
| --- | --- |
| `/` | hero, category tabs, first 8 products |
| `/products` | the one listing page: category tabs, filters (size, price, in stock, featured), sort, grid columns |
| `/products/[slug]` | product page: photos by colour, size and colour pickers, add to cart, related products |
| `/checkout` | cart review. Payment is not built yet (Stripe is disabled, "Proceed to Payment" does nothing) |

There is no separate category page: a category is `/products?category=hoodies`. There is also no
search and no quick view.

State lives in the URL (`?category=hoodies&size=M&minPrice=20`) and is validated in `src/schema`.
Anything invalid falls back to a default, and `resolveListingParams` redirects to the same page
with only the valid params kept (`/products?category=red` becomes `/products`), so a hand-edited
URL never breaks the page.

## Code layout

- `src/app/(routes)/<route>/_modules/{views,sections,components}`: code used by one route only.
- `src/features/product-listing`: the `/products` listing (server section that filters and sorts,
  list toolbar, filter sidebar and mobile sheet, sort select, grid column toggle).
- `src/components/global-ui`: pieces shared between routes (product card, product grid, category
  tabs, colour and size pickers).
- `src/utils`: pure helpers (`filter-products`, `sort-products`, `product-variants`, ...).
- `src/hooks`: cart (zustand, persisted), wishlist, URL search-param helper.

## Product data (`src/data/data.ts`)

```ts
{
  id: "5",
  slug: "classic-fleece-hoodie",          // unique, used in the URL
  name, description,
  category: "hoodies",                    // must be a slug from src/data/categories.ts
  colors: [                               // defined once; first colour = card image
    { name: "Black", code: "#2b2f33", image: "/assets/products/5bl.png" },
  ],
  sizes: [
    {
      size: "M",                          // must exist in src/data/sizes.ts
      price: 39.99,
      discount: 4,                        // amount off (not %), omit for none
      stock: { Black: 18, Orange: 10 },   // keys must be colour names
    },                                    //   0 = sold out, key missing = not made in this size
  ],
  isNew, isFeatured, isArchived,          // archived products are hidden everywhere
  createdAt: "2024-06-10T14:20:00Z",
}
```

**Adding a category:** add it to `src/data/categories.ts` (pick a lucide icon). The tabs, footer
links and URL validation all follow.
**Adding a size** (e.g. `"XXL"` or `"One Size"`): add it to `src/data/sizes.ts` first.

Prices are plain dollars (`19.99`). Convert to integer cents when you wire up payments.
